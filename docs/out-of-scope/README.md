# Реестр осознанных отказов

Сюда записывается то, что решено **не делать**, — с причиной и с тем, что есть взамен.

Зачем отдельный файл: без него отказ живёт прозой в описании версии, не обновляется и через
пару выпусков превращается в «кажется, мы это умеем». Запись здесь — обязательство честности:
если механизма нет, это написано там же, где написано про механизмы.

Правило: запись появляется в момент решения, а не задним числом. Решение о том, что фича не
нужна, принимает владелец; агент может предложить и обосновать, но не закрыть вопрос сам.

Формат файла: `<тема>.md` — что не делаем / почему / что взамен / при каком условии вернуться.
